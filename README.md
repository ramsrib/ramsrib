## Sriram Balasubramanian

I build tools for working with AI agents, and I use them all day to find out which
ones hold up. Almost everything here started the same way: something in the daily
loop broke or annoyed me, so I built the thing that fixed it.

I build voice AI infrastructure at [@VapiAI](https://github.com/VapiAI) during the day.

### What I'm building

- **[temple](https://github.com/ramsrib/temple)** — an IDE for your Claude Code and
  Codex agents. Sessions organized by project, all a click away.
- **[folio](https://github.com/ramsrib/folio)** — a read-optimized Markdown app for
  macOS. Agents write most of my docs now; this is the reader for them.
- **[recall](https://github.com/ramsrib/recall-cli)** — hybrid semantic + full-text
  search over every Claude Code and Codex session you've run. Nothing leaves the machine.
- **[tarp](https://github.com/ramsrib/tarp)** — a plain, modern terminal. Warp with the
  AI, the cloud, and the account system pulled out.
- **[abra](https://github.com/ramsrib/abra)** — hold Fn, speak, release. On-device
  dictation for macOS.
- **[raven](https://github.com/ramsrib/raven)** — terminal dashboard for the Claude Code
  sessions running on your machine, showing which one needs you.

Plus smaller ones: [`later`](https://github.com/ramsrib/later) (leave a reminder for a
future agent session), [`ccmeter`](https://github.com/ramsrib/ccmeter) (what's left of
the subscription, and of the context window),
[`clipwire`](https://github.com/ramsrib/clipwire) (paste screenshots into a CLI running
over SSH).

A theme, if there is one: local-first, files on disk, no telemetry, no account.
